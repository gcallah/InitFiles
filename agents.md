# Agent Instructions

Always work on the trunk branch, whether it is called `main` or `master`

Write scripts in the `bin` directory, and make sure they are executable, for any
repeated tasks you need to perform. This will make it easier to automate your workflow and share your scripts with others.

When writing scripts, follow best practices for readability and maintainability.
Use clear variable names, add comments where necessary, and structure your code
logically.

Markdown files containing the text '[*image*] indicate where to place an image.
First search the `graphics` folder for an image with a similar name. If nothing
is found there, then search the Internet for a suitable image. If you find an
image, download it and place it in the `graphics` folder. If you cannot find a suitable image, leave the placeholder as is.

Images mixed in with text should never take up the entire width of the page.
Limit them to about 66% of the width.
